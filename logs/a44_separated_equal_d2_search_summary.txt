A44 separated-equal D2 stronger local search summary
=====================================================

Tool represented by:
  scripts/search_separated_equal_d2_model.py

Independent local reproduction of the same search logic was run for:
  p in {5,7,11}
  |A|,|G|,|C|,|Y| <= 2
  total local length <= p-1
  require_balanced = true
  require_local_graham = true
  up to 3 examples per length configuration

Interpretation guardrail:
  These examples satisfy a stronger local model than A42, but still do not enforce the full global endpoint-avoidance framework.
  A found example is not a counterexample to Erdős 475 or endpoint avoidance.

Constraints checked:
  1. A,G,C,Y consist of distinct nonzero atoms in F_p^*.
  2. sum(A)=sum(C).
  3. D2 is active: C_k = 2a + g + Y_m.
  4. Balanced transfer is required: m=k.
  5. The A41 residual difference-walk condition holds for prefix_k(C), prefix_k(Y).
  6. Other direct-exchange collision branches are absent for all prefixes:
       D1: C_k = a + G_j
       D3: A_i = G_j - g
       D4: A_i = a + Y_m
       D5: C_k = a + g + A_i
  7. The local concatenated segment A G C Y has distinct nonempty partial sums.

Sweep result:
  total length configurations tested: 28
  configurations with survivors: 10

Important observation:
  Stronger A44 local constraints still do not eliminate balanced D2.
  The earliest survivors are boundary transfers with k=m=1.
  Therefore the next analytic split should isolate the case k=1 from the proper balanced-transfer case k>=2.

  The surviving examples are dominated by k=m=1, which has no intermediate difference-walk values. The A41 descent mechanisms based on intermediate D_r cannot apply.

Next analytic target:

  For k=m=1, D2 reads:
