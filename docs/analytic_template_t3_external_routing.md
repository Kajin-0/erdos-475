## T3 parent template

Right singleton blocker:

```text
a,b,-a  ->  -a,b,a.
```

Original relative partial sums:

```text
a,
a+b,
b.
```

Forbidden relative value:

```text
a.
```

New relative values:

```text
W_1=-a,
W_2=b-a.
```

Internal scalar branch:

```text
b=2a.
```

This branch is routed to scalar absorption.

External branches:

```text
E1: K+(-a)=0,       sum(K)=a.
E2: (b,a)+K=0,      sum(K)=-a-b.
E3: K+(-a,b)=0,     sum(K)=a-b.
E4: (a)+K=0,        sum(K)=-a.
```

This note routes these four branches to reusable interval templates.

## E1 routes to duplicate-left interval `Left(a)`

E1 has a left interval `K` immediately before the active block with

```text
sum(K)=a.
```

The combined original local form is

```text
K, a, b, -a.
```

Since `a` is already a local atom, this is a duplicate-target left interval:

```text
Left(a).
```

Template-aware cancellation meaning:

```text
K+(-a)=0.
```

This should be handled by the duplicate-left splitting module:

```text
K=z,J,
sum(K)=a,

z,J,a,b,-a  ->  z,a,b,J,-a.
```

Expected failure menu:

```text
success,
affine/singleton,
proper prefix inside J,
external cancellation,
impossible condition.
```

This is not a new obstruction class.

## E3 routes to nonduplicate/generic-left interval `Left(a-b)`

E3 has a left interval `K` immediately before the active block with

```text
sum(K)=a-b.
```

The combined original local form is

```text
K,a,b,-a.
```

This is a left interval target:

```text
Left(a-b).
```

Template-aware cancellation meaning:

```text
K+(-a,b)=0.
```

If `a-b` equals a local atom, the branch is duplicate/impossible/special. Otherwise:

```text
|K|=1:
  handled by the generic left length-one interval template.

|K|>=2:
  handled by the generic left splitting template.
```

Expected moves:

Length-one:

```text
T,a,b,-a  ->  b,a,T,-a,
where T=a-b.
```

Length at least two:

```text
K=z,J,
sum(K)=T,

z,J,a,b,-a  ->  z,a,b,J,-a.
```

This is not a new obstruction class, but it depends on packaging the generic-left interval module.

## T3 routing theorem

### Statement

For the right singleton blocker template

```text
a,b,-a  ->  -a,b,a,
```

every non-scalar external branch routes to one of four reusable interval modules:

```text
E1 -> duplicate-left   Left(a),
E4 -> duplicate-right  Right(-a),
E3 -> generic-left     Left(a-b),
E2 -> generic-right    Right(-a-b).
```

The scalar branch `b=2a` routes to scalar absorption.

Therefore T3 introduces no new obstruction type beyond:

```text
duplicate interval templates,
generic interval templates,
scalar absorption,
external-cancellation/bridge routing generated by those templates.
```

### Proof

The four external branches were classified in `analytic_template_t3_right_singleton_blocker.md` by external collision normal form. Matching each cancellation equation with the adjacent real interval gives exactly the four interval targets listed above. The template-aware canceled prefix/suffix is retained in each case. ∎

## Significance

This is a meaningful simplification.

T3 does not require a full independent eight-branch external-cancellation analysis like T1. Its external children are primitive interval states that should be closed by two reusable modules:

```text
1. duplicate-target interval splitting;
2. generic nonduplicate interval length-one/splitting.
```
