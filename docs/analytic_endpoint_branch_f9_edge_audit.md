### 3. PROPER_SUBINTERVAL

Endpoint branch outputs include:

```text
proper prefix inside J,
proper suffix inside K',
proper internal subinterval inside J,
proper internal subinterval inside K',
proper subinterval caused by cross-prefix equality inside one tail.
```

F9/F3 classes:

```text
PREFIX_ZERO,
SIGNED_INTERVAL,
EQUAL_INTERVAL,
TRANSPORTED_PREFIX,
TWO_PIECE_ZERO,
PAIR_DIFFERENCE
```

depending on equation form.

Expected F9 route:

```text
F4 local descent -> F9.1.
```

Measure obligation:

```text
The active support must be a strict subinterval of the parent active support, or have strictly smaller support_size.
```

Status:

```text
Mostly clear for all packaged modules.
Needs final line-by-line verification in manuscript form.
```

Risk:

```text
Cross-prefix equations inside one tail must always be converted to a genuine nonempty proper subinterval, not merely a relation between two equal prefixes.
```

Risk:

```text
Need final proof that every bridge generated by GEN-L/GEN-R external routes also satisfies F8 hypotheses or exits through F6 first.
```

### 6. AFFINE_SINGLETON

Endpoint branch outputs include equations of the form:

```text
z = T_*,
y = T_*,
T = T_*,
linear scalar condition involving one active atom.
```

F9/F3 class:

```text
SINGLETON_RECURRENCE,
PAIR_DIFFERENCE,
TRANSPORTED_PREFIX
```

or immediate contradiction if the singleton duplicates a local atom or equals zero.

Expected route:

```text
singleton routing -> GEN-L1/GEN-R1 or duplicate interval theorem or scalar absorption.
```

Measure obligation:

```text
A finite sequence of affine/singleton routings must either:
  1. terminate by contradiction;
  2. enter length-one interval modules;
  3. enter scalar absorption;
  4. enter F7 recurrence routing;
  5. decrease type_rank or recurrence_depth.
```

Status:

```text
Conceptually clear but not fully packaged as a theorem.
```

Risk:

```text
This is currently one of the main remaining formal gaps.
Need a durable Singleton Routing Theorem matching F7/SINGLETON_RECURRENCE.
```

The endpoint branch local output classes all land inside the F9/F3 class universe.

```text
EXTERNAL_COLLISION,

local zero/equal/signed interval classes,

```

Thus the endpoint-avoidance branch is compatible with the existing F9 state machine.

## Remaining high-risk gaps

### Gap 1: Singleton Routing Theorem

Need to package:

```text
Every affine/singleton equation z=T_* produced by local modules either:
  - contradicts nonzero/distinctness;
  - becomes a duplicate interval target;
  - becomes GEN-L1/GEN-R1;
  - becomes scalar absorption;
  - or enters F7 recurrence routing with controlled recurrence_depth.
```

### Gap 2: Boundary Zero Lemma

Need to package:

```text
Interior relative zero is terminal contradiction.
Boundary relative zero either is allowed only as final global endpoint behavior or admits explicit finite repair.
```

### Gap 3: F6 edge compatibility audit

Need to check that F6 outputs from template-aware external cancellations match F9.3 exactly and do not bypass measure descent.

### Gap 4: Fixed-ordering vs current-ordering formalism

Need a lemma saying:

```text
F6/F9 equations remain valid when local moves are hypothetical inside a fixed minimal Graham-valid ordering.
```

This was noted in the F6 embedding note but not yet proved as a standalone formal lemma.
