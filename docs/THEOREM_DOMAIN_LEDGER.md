## Claim boundary

## Trust tiers and artifact classes

### Tier 1: verified finite-certificate evidence

A finite domain is Tier 1 when verified finite-certificate evidence exists for every canonical representative in the declared domain.

Artifact storage is tracked separately.

### Tier 1A: committed or repository-checkable artifact

Tier 1A means all artifacts needed for routine repository verification are committed or generated by repository scripts, and the Python/Rust verifiers can check them.

Current Tier 1A summary:

```text
p = 17, |B| = 3
p = 19, |B| = 3..5
p = 23, |B| = 3..9
p = 29, |B| = 3..8
p = 31, |B| = 3..6
```

### Tier 1B: verified local/external artifact

Tier 1B means the domain has already passed verification using local or external JSONL artifacts, but the raw files are not committed to Git due to size.

Current Tier 1B JSONL summary:

```text
p = 29, |B| = 9..15
p = 31, |B| = 7..16
```

Current Tier 1B summary-digest domain:

```text
p = 31, |B| = 17
```

Tier 1B should be described as verified finite evidence, but not as routine Git/CI-checkable until artifact retrieval, hashes, and reproduction instructions are hardened for independent reviewers.

### Tier 3: unhardened research evidence

Tier 3 is reserved for research-only evidence not yet suitable for finite-certificate claims. No currently declared finite domain is intentionally classified as Tier 3 in `certificates/verified_domains.json` after the p=29 and p=31 verification status correction.

## Current theorem statement

For each finite complement domain listed above, the project records evidence that every canonical multiplicative-scaling representative B admits an ordering of A = F_p^* \ B whose nonempty partial sums are pairwise distinct modulo p.

Tier 1A domains are routinely checkable inside the repository.

Tier 1B domains are verified finite evidence but require external/local artifact access or summary-digest verification details before independent public release review.

## Not yet proved

The repository does not yet prove that the analytic residue of Erdős 475 is contained in the verified finite domain.

The missing bridge is:
