## Residual structure

The worse-only examples in both p=17 and p=23 overwhelmingly show:

```text
D_short = (1, 3, 1, [2])
```

and usually only:

```text
LONG_TERMINAL_BRIDGE = 2
RIGHT_TERMINAL_BRIDGE = 2
```

with no left terminal, no clean descent, and often no distributed/signed branch.

This means the hard residue is now much more specific:

```text
one-sided right-long-terminal,
unique shortest zero interval of length 3,
one collision pair,
all tested local permutations worse.
```

## Interpretation

The previous branch:

```text
one-sided long terminal
```

has compressed into:

```text
1. finite-menu descent branch;
2. neutral/progress branch;
3. worse-only D_short=(1,3,1,[2]) residual branch.
```

The finite descent menu is:

```text
M1 = z q A B
M2 = A B q z
M3 = z q B A
M4 = B A q z
```

The neutral menu likely requires an additional tie-break coordinate tracking terminal support progress, boundary position, or location of the unique collision.

The worse-only residue likely needs special analysis for `m=3`.

## Candidate finite-menu lemma

Let

```text
R = X A z q B Y,
Z=A z,
sum(Z)=0,
z+sum(B)=0,
sum(A)=sum(B),
```

with `Z` an active shortest zero interval and the right terminal bridge long.

Then at least one of the four moves

```text
z q A B,
A B q z,
z q B A,
B A q z
```

either:

```text
1. decreases D_short;
2. preserves D_short while increasing a terminal-progress coordinate;
3. routes to the special m=3 residual branch.
```

## Special m=3 residual

In the worse-only examples, `D_short=(1,3,1,[2])` appears repeatedly.  This means:

```text
E = 1
L_min = 3
N_min = 1
M = [2]
```

There is one collision and one shortest zero interval of length 3.

For `m=3`, write

```text
Z = a b z,
A = a b,
sum(A)=B,
z+B=0.
```

Then

```text
a+b = B,
z = -B,
a+b+z=0.
```

The terminal bridge simply externalizes the two-atom prefix `a+b` as a long support `B`.

The next proof attack should specialize this case.
