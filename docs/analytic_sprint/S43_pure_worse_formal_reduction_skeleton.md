# S43. Formal reduction skeleton for the pure worse-only branch

This note converts the empirical branch work into a proof skeleton.

## 1. Normal form

Work in `Z/pZ`.  The hard residual branch has the form

```text
R = X A z q B Y,
A = A1 A2,
A1 + A2 + z = 0,
sum(B) + z = 0.
```

Equivalently,

```text
A + z = 0,
sum(A) = sum(B) = -z.
```

The local terminal window is

```text
A z q B.
```

The current short defect is

```text
D_short = (1,3,1,[2]).
```

The branch under consideration is the pure worse-only branch: all tested local block permutations fail to produce an immediate `D_short` descent or previously classified bridge descent.

## 2. Hidden support extraction lemma

### Lemma 1: B z q A exposes a hidden support equation

In every observed pure worse-only `m=3` right-terminal residual, the permutation

```text
B z q A
```

exposes one of the following reduced hidden-support equations:

```text
1. B_tail + q = 0
2. B_tail + q + Y_prefix = 0
3. B_tail + q = A_complement
4. B_prefix = q
```

Observed certificate:

```text
p=17: 35 / 35 records extracted and verified.
p=23: 59 / 59 records extracted and verified.
```

The refined family split is:

```text
p=17:
  B_tail+q                  = 23
  B_tail+q+Y_prefix          =  8
  B_tail+q=A_complement      =  4

p=23:
  B_tail+q                  = 20
  B_tail+q+Y_prefix          = 32
  B_tail+q=A_complement      =  5
  B_prefix=q                =  2
```

### Algebraic derivation

The hidden symbolic block falls into one of three forms.

#### Full-A tail-core

```text
B_tail + z + q + A1 + A2 + Y_prefix = 0.
```

Using

```text
A1 + A2 + z = 0,
```

this reduces to

```text
B_tail + q + Y_prefix = 0.
```

If `Y_prefix` is empty, this is

```text
B_tail + q = 0.
```

#### Partial-A tail-core

```text
B_tail + z + q + A_i + Y_prefix = 0.
```

Since

```text
z + A_i = -A_j,
```

where `{i,j}={1,2}`, this reduces to

```text
B_tail + q + Y_prefix = A_j.
```

In the observed samples this appears as

```text
B_tail + q = A_complement.
```

#### Prefix-core

```text
B_tail + z + q = 0.
```

Since

```text
B_prefix + B_tail + z = 0,
```

subtracting gives

```text
B_prefix = q.
```

## 3. Zero-sum secondary obstruction lemma

### Lemma 2: Zero-sum hidden-support branches force Bq/BqY secondary obstruction

If the hidden support equation is one of the zero-sum types

```text
B_tail + q = 0
B_tail + q + Y_prefix = 0,
```

then every best bridge realization either descends or creates a genuine secondary zero interval of the same support/exterior type.

Observed behavior in the current samples: no tested bridge realization descends; every one produces the corresponding secondary obstruction.

Observed coverage:

```text
B_tail+q -> Bq_zero:
  p=17: 23 / 23
  p=23: 20 / 20

B_tail+q+Y_prefix -> BqY_zero:
  p=17:  8 /  8
  p=23: 32 / 32
```

Thus the zero-sum branch is self-replicating under naive bridge realization:

```text
attempt to realize B_tail+q(+Y_prefix)=0
  -> genuine Bq/BqY secondary collision.
```

### Proof target

Prove that this secondary collision routes to one of the already known branch mechanisms:

```text
SIGNED_INTERVAL
EXTERNAL_BRIDGE
DISTRIBUTED_BRIDGE
PAIR_TRAP / support-tail trap
```

or define it as a new branch lemma:

```text
Bq/BqY support-exterior obstruction lemma.
```

## 4. Equality branch tie-break lemma

### Lemma 3: Equality branches are neutral under current moves

The equality branches are

```text
B_tail + q = A_complement
B_prefix = q.
```

Observed behavior:

```text
p=17:
  B_tail+q=A_complement -> neutral 4 / 4

p=23:
  B_tail+q=A_complement -> neutral 5 / 5
  B_prefix=q            -> neutral 2 / 2
```

No genuine secondary obstruction is generated by the current best move menu for these branches.

### Proof target

These branches likely need a refined tie-break rather than another local descent move.

Candidate refined defect:

```text
D_ref = (D_short, terminal_position_rank, cyclic_rank, support_rank).
```

Possible ranks:

```text
terminal_position_rank:
  right distance of the unique zero triple for right-terminal residuals;
  left distance for left-terminal residuals.

cyclic_rank:
  canonical cyclic rank of the unique triple A1 A2 z.

support_rank:
  lexicographic or support-prefix rank involving the location of q relative to B_prefix/B_tail.
```

The equality branches should be shown to decrease one of these ranks while preserving `D_short`.

## 5. Main proposition to prove

### Proposition: Pure worse-only is not terminal

Assume `R = X A z q B Y` is a pure worse-only `m=3` right-terminal residual with

```text
A+z=0,
B+z=0,
D_short=(1,3,1,[2]).
```

Then one of the following occurs:

```text
1. A tested block permutation gives D_short descent.
2. A tested block permutation gives neutral progress in D_ref.
3. The B z q A permutation exposes a zero-sum hidden support equation, which forces a Bq/BqY secondary obstruction.
4. The B z q A permutation exposes an equality hidden support equation, which is neutral but decreases a refined tie-break rank.
```

Therefore the pure worse-only branch is reducible once the Bq/BqY obstruction lemma and equality tie-break lemma are formalized.

## 6. Remaining proof obligations

### Obligation A: Formalize extraction without enumeration

Prove that in the pure worse-only branch, the B z q A permutation must create a non-tautological zero interval of one of the following forms:

```text
B_tail + z + q + A1 + A2 + Y_prefix = 0,
B_tail + z + q + A_i + Y_prefix = 0,
B_tail + z + q = 0.
```

This is the main nontrivial structural proof.

### Obligation B: Formalize zero-sum secondary obstruction

Prove that a failed bridge realization of

```text
B_tail+q=0
```

or

```text
B_tail+q+Y_prefix=0
```

must expose a genuine secondary collision of type

```text
Bq_zero
```

or

```text
BqY_zero.
```

### Obligation C: Route Bq/BqY obstruction

Prove that the Bq/BqY secondary obstruction is covered by an earlier descent mechanism or define a new descent/tie-break for it.

### Obligation D: Equality branch tie-break

Prove that the equality branches

```text
B_tail+q=A_complement,
B_prefix=q
```

preserve `D_short` but decrease a refined tie-break rank.
