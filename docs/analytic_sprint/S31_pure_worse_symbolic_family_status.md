## Algebraic reading

Recall the normal form:

```text
R = X A z q B Y,
A = A1 A2,
A1 + A2 + z = 0,
sum(B) = A1 + A2 = -z.
```

Thus:

```text
A_all+B_prefix = 0
```

means:

```text
sum(B) + B_prefix = 0.
```

Equivalently:

```text
B_tail = -2 B_prefix
```

where `B = B_prefix + B_tail`.

Also:

```text
A_suffix+B_prefix = 0
```

means:

```text
A2 + B_prefix = 0.
```

This is close to a signed/pair obstruction.

And:

```text
B_tail+zq+A = 0
```

using `z+A=0`, reduces to:

```text
B_tail + q = 0.
```

So this family is effectively a hidden terminal/signed relation between `q` and a tail of `B`.
