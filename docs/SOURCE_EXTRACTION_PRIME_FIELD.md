# Source extraction: prime-field analytic coverage

This document extracts the analytic coverage inputs needed to turn the finite-certificate package into a full prime-field proof, if the resulting residue is contained in the verified finite domain.

The purpose is not to summarize the literature generally.  The purpose is to identify which statements can be encoded as rigorous residue-audit rules.

## 1. Required audit fields

For each source theorem, the repository needs:

```text
source_id
authors
title
version/date
theorem number
exact statement
prime hypotheses
set-size hypotheses
exceptional cases
effective constants / threshold status
translation to (p,t)
translation to (p,|B|)
audit-rule status
```

Only statements with exact hypotheses should be converted into `scripts/reduction_residue_audit.py --range` rules.

## 2. Pham--Sauermann 2026

```text
source_id: pham_sauermann_2026_large_prime
authors: Huy Tuan Pham; Lisa Sauermann
title: On Graham's rearrangement conjecture
arXiv: 2602.15797
url: https://arxiv.org/abs/2602.15797
submitted: 2026-02-17
```

### Extracted public statement

The arXiv abstract states that for any `alpha in (0,1)`, the conjecture is proved for all subsets

```text
S subset Z_p \ {0}
```

with

```text
|S| <= p^(1-alpha)
```

and

```text
|S| sufficiently large with respect to alpha.
```

It also states that, combined with earlier results, this gives a complete resolution for all sufficiently large primes `p`.

### Translation

In this repository's notation:

```text
A = S
t = |A|
```

The source gives a medium-size coverage interval of the form:

```text
N_alpha <= t <= p^(1-alpha)
```

for sufficiently large `p`, where `N_alpha` and the prime threshold still need to be extracted from the paper.

### Audit status

```text
theorem_number: pending PDF/TeX extraction
exact constants: pending
explicit P_alpha: pending
usable audit rule: not yet
```

The correct placeholder form is:

```text
--range "p>=P_alpha,t=N_alpha..floor(p^(1-alpha)),name=pham_sauermann_alpha"
```

but this cannot be used until `P_alpha`, `N_alpha`, and the dependence on `alpha` are extracted or bounded.

## 3. Bedert--Kravitz 2024/2025

```text
source_id: bedert_kravitz_2024_small_prime_field_sets
authors: Benjamin Bedert; Noah Kravitz
title: Graham's rearrangement conjecture beyond the rectification barrier
arXiv: 2409.07403
url: https://arxiv.org/abs/2409.07403
submitted: 2024-09-11
revised: 2025-01-07
```

### Extracted public statement

The arXiv abstract states that the conjecture is proved for sets of size

```text
|A| <= exp((log p)^(1/4)).
```

The ar5iv page identifies this as the main result, Theorem 1.2, but formula extraction is incomplete in the HTML rendering.  The source PDF/TeX should be used before encoding this as an exact audit rule.

### Translation

```text
t <= exp((log p)^(1/4))
```

or, in complement notation,

```text
|B| >= p - 1 - exp((log p)^(1/4)).
```

This is a small-original-set theorem, not a small-complement theorem.

### Audit status

```text
theorem_number: Theorem 1.2, pending PDF/TeX confirmation
exact constants / large-prime condition: pending
usable audit rule: not yet
```

The eventual audit rule should be generated by a script, not a fixed `--range`, because the endpoint depends on `p`.

## 4. Bedert--Bucić--Kravitz--Montgomery--Müyesser 2025

```text
source_id: bbkmm_2025_large_sets_general_groups
authors: Benjamin Bedert; Matija Bucić; Noah Kravitz; Richard Montgomery; Alp Müyesser
title: On Graham's rearrangement conjecture over F_2^n
arXiv: 2508.18254
url: https://arxiv.org/abs/2508.18254
submitted: 2025-08-25
```

### Extracted public statement

The arXiv abstract states that there exists a constant `c > 0` such that for every group `G`, every subset

```text
S subset G \ {id}
```

of size at least

```text
|G|^(1-c)
```

admits a valid ordering.

### Translation to prime fields

For the additive group `F_p`, this gives coverage for

```text
t >= p^(1-c).
```

In complement notation:

```text
|B| <= p - 1 - p^(1-c).
```

This is a large-original-set theorem.

### Audit status

```text
theorem_number: pending PDF/TeX extraction
exact c: pending
prime/group threshold or finite exceptions: pending
usable audit rule: not yet
```

The eventual audit rule should be generated by a script, because the endpoint depends on `p` and on the extracted value of `c`.

## 5. Costa--Della Fiore--Fontana--Vena 2026

```text
source_id: costa_dellafiore_fontana_vena_2026_abelian_small_sets
authors: Simone Costa; Stefano Della Fiore; Mattia Fontana; Lluís Vena
title: Graham conjecture on small sets in abelian groups
arXiv: 2603.20961
url: https://arxiv.org/abs/2603.20961
submitted: 2026-03-21
```

### Extracted public statement

The arXiv abstract states:

```text
1. The prime-field conjecture was recently proved for sufficiently large primes
   by Pham--Sauermann combined with earlier results.
2. The broader problem remains open for general abelian groups, even cyclic groups Z_k.
3. Every subset A subset G\{0} with |A| <= 20 is sequenceable.
4. The bound improves to |A| <= 22 for zero-sum subsets.
5. For the related CMPP conjecture, zero-sum subsets without inverse pairs are sequenceable for |A| <= 23.
```

### Audit role

This source is primarily useful for:

```text
1. confirming the current literature landscape;
2. motivating a future cyclic/abelian generalization track;
3. improving small-set bounds outside the prime-field setting.
```

It is not currently the primary finite-residue closure source for the prime-field theorem.

## 6. Coverage sandwich status

The abstract interval logic is recorded in:

```text
docs/COVERAGE_SANDWICH_LEMMA.md
```

The required inputs are:

```text
Input S: t <= S(p)
Input M: N_alpha <= t <= p^(1-alpha)
Input L: t >= p^(1-c)
```

If `alpha < c` and the constants are effective, then all sufficiently large primes are covered.  The remaining task is to compute the finite threshold and audit all primes below it.
